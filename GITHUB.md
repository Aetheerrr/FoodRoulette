# 📘 Как выложить «Рулетку еды» на GitHub и подключить к Telegram

Итог: приложение будет жить по бесплатному адресу вида `https://ТВОЙ-ЛОГИН.github.io/food-roulette/`, а в Telegram-боте появится кнопка, которая его открывает.

Займёт 10–15 минут. Понадобятся аккаунт на GitHub и Telegram.

---

## Шаг 1. Аккаунт на GitHub

Если аккаунта нет, зарегистрируйся на https://github.com/signup.
Запомни **логин** (username): он станет частью адреса приложения.

---

## Шаг 2. Создать репозиторий

1. Открой https://github.com/new
2. Заполни:
   - **Repository name:** `food-roulette` (можно любое имя латиницей, без пробелов);
   - видимость **Public**, иначе бесплатный GitHub Pages не заработает;
   - галочки «Add a README», «.gitignore» и «license» **не ставь**.
3. Нажми **Create repository**.

---

## Шаг 3. Загрузить файлы

Выбери **один** из вариантов.

### Вариант А — через сайт, без программ (проще)

1. На странице нового репозитория нажми ссылку **uploading an existing file**.
   Если её нет, нажми **Add file → Upload files**.
2. Открой папку `C:\FoodRoulette` в проводнике, выдели **всё содержимое** и перетащи в окно браузера:
   - `index.html`
   - папку `css`
   - папку `js`
   - `README.md`, `GITHUB.md`
   - `.nojekyll` (если виден)

   Перетаскивай именно **содержимое** папки, а не саму `FoodRoulette`. Иначе `index.html` окажется внутри подпапки и сайт не откроется.

   Папки `.claude` и файл `dev-server.js` загружать не обязательно.
3. Подожди, пока загрузятся все файлы, и нажми зелёную кнопку **Commit changes**.
4. Проверь: в корне репозитория должны лежать `index.html`, `css/`, `js/`.

### Вариант Б — через git (если привык к командной строке)

Открой терминал в папке `C:\FoodRoulette` и выполни по очереди. Вместо `ТВОЙ-ЛОГИН` подставь свой логин:

```bash
git init -b main
```

```bash
git add .
```

```bash
git commit -m "Рулетка еды"
```

```bash
git branch -M main
```

(Последняя команда переименует ветку в `main`, если git создал её под именем `master`. Если ветка уже называется `main`, команда ничего не испортит.)

```bash
git remote add origin https://github.com/ТВОЙ-ЛОГИН/food-roulette.git
```

```bash
git push -u origin main
```

При первом `push` откроется окно входа в GitHub, войди в аккаунт.

> Предупреждения вида `LF will be replaced by CRLF` — это не ошибка, а особенность Windows. Файл `.gitattributes` в проекте их отключает.

---

## Шаг 4. Включить GitHub Pages

1. В репозитории открой **Settings** (шестерёнка вверху) → в меню слева **Pages**.
2. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` и папка `/ (root)` → **Save**.
3. Подожди 1–2 минуты и обнови страницу. Вверху появится строка
   **«Your site is live at https://ТВОЙ-ЛОГИН.github.io/food-roulette/»**.
4. Открой эту ссылку на телефоне: должна загрузиться рулетка.

Если видишь ошибку 404, подожди ещё пару минут и проверь, что `index.html` лежит в корне репозитория, а не в подпапке.

Ход публикации можно смотреть во вкладке **Actions**: зелёная галочка значит «готово».

---

## Шаг 5. Создать бота в Telegram

1. Найди в Telegram **@BotFather** и нажми **Start**.
2. Отправь `/newbot`.
3. Введи **имя** бота, которое увидят люди, например `Рулетка еды`.
4. Введи **username**: латиницей, должен заканчиваться на `bot`, например `my_food_roulette_bot`.
5. BotFather пришлёт сообщение с токеном. **Токен никому не показывай.** Для этого приложения он не нужен.

---

## Шаг 6. Привязать приложение к боту

### Кнопка в меню чата (обязательно)

1. В @BotFather отправь `/mybots` → выбери своего бота.
2. **Bot Settings → Menu Button → Configure menu button**.
3. Отправь ссылку из шага 4: `https://ТВОЙ-ЛОГИН.github.io/food-roulette/`
4. Отправь название кнопки, например `🎰 Крутить`.

Теперь открой чат со своим ботом, нажми **Start**: слева от поля ввода появится кнопка «🎰 Крутить».

### Прямая ссылка на приложение (по желанию)

Нужна, чтобы кидать друзьям ссылку, которая сразу открывает рулетку.

1. В @BotFather отправь `/newapp` → выбери бота.
2. Введи название, описание и отправь картинку 640×360: готовая лежит в `assets/cover-640x360.png`.
3. GIF можно пропустить командой `/empty`.
4. Отправь ссылку из шага 4.
5. Придумай короткое имя, например `app`.

Получится ссылка вида `https://t.me/my_food_roulette_bot/app`.

### Ссылка в кнопке «Поделиться» (по желанию)

Чтобы в сообщениях «Рулетка решила…» была ссылка на твоё приложение:

1. На GitHub открой файл `js/app.js` → значок карандаша ✏️ (Edit).
2. В самом начале замени `botUrl: ''` на свою ссылку:
   ```js
   botUrl: 'https://t.me/my_food_roulette_bot/app',
   ```
3. Нажми **Commit changes**.

---

## Как обновлять приложение

- **Через сайт:** открой нужный файл на GitHub → ✏️ → поправь → **Commit changes**.
  Новый файл можно загрузить поверх старого через **Add file → Upload files**.
- **Через git:** после правок выполни:
  ```bash
  git add .
  ```
  ```bash
  git commit -m "Обновление"
  ```
  ```bash
  git push
  ```

Через 1–2 минуты сайт обновится. Telegram иногда держит старую версию в кэше. Тогда полностью закрой мини-приложение и открой снова. Если не помогло, перезапусти Telegram.

Данные пользователей (продукты, история, избранное) при обновлении **не теряются**: они хранятся на их телефонах.

---

## Частые проблемы

| Проблема | Что делать |
|---|---|
| 404 на github.io | Подожди 2–5 минут. Проверь, что репозиторий **Public** и `index.html` лежит в корне |
| Белый экран | Проверь, что папки `css` и `js` загрузились вместе со всеми файлами внутри |
| В боте нет кнопки | Перезайди в чат с ботом. Проверь, что в Menu Button указана ссылка, начинающаяся с `https://` |
| Не работает встряска | Нужен свежий Telegram (Bot API 8.0+). Проверь, что в настройках приложения включено «Встряхнуть, чтобы крутить» |
| Изменения не видны | Подожди пару минут, затем закрой и снова открой приложение (см. «Как обновлять») |
