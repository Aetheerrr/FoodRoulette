# 🎰 Рулетка еды — Telegram Mini App

Не знаешь, что приготовить? Крути барабаны: **Гарнир × Основа × Способ** (и по желанию **Соус**). Продукты свои: добавляй, переименовывай, ставь эмодзи или фото.

Без сервера и без сборки: обычные HTML/CSS/JS-файлы. Их нужно выложить на любой HTTPS-хостинг и указать ссылку в @BotFather.

## Что умеет

| | |
|---|---|
| 🎰 **Рулетка** | 3–4 барабана, свайп, стрелки, анимация с «отскоком», вибрация и щелчки, конфетти |
| 🔓 **Фиксация колонки** | Замок у заголовка: например, «Картофель» оставить, остальное перекрутить |
| 👆 **Перекрутить одну** | Тап по центральной ячейке крутит только эту колонку |
| 📳 **Встряхни телефон** | Трясёшь телефон, и рулетка крутится (акселерометр Telegram, Bot API 8.0+) |
| ✏️ **Свои продукты** | Название, эмодзи из палитры или **фото с телефона**, вкл/выкл |
| ⭐ **Шанс выпадения** | Обычный / Чаще (×2) / Любимое (×3) |
| ➕ **Свои колонки** | До 4 колонок, любые названия («Десерт», «Напиток»…) |
| 🎯 **Челлендж от шефа** | Случайное условие: «уложись в 30 минут», «добавь сыр» и т.п. |
| 👨‍🍳 **Кто готовит, кто моет** | Рулетка заодно выбирает дежурных из списка людей |
| 🔁 **Не повторять** | Не выкидывать блюда, которые готовили последние 3/7/14 дней |
| ❤️ **Любимое и джекпот** | Сохраняй сочетания; если любимое выпадет снова, будет «джекпот». Из избранного блюдо можно поставить на барабаны |
| 🧠 **Здравый смысл** | Рулетка не предлагает «варёный стейк» и «пельмени с гречкой». У каждого продукта есть список «Не сочетается с…», его можно менять в редакторе. Если выключить, включится безумный режим 🤪 |
| 🔎 **Рецепт** | Ищет рецепт в Яндексе по нормальной фразе: «Куриные ножки на сковороде с картофелем рецепт», «Как потушить говядину с рисом и сливочным соусом» |
| 📤 **Поделиться** | Отправить результат в любой чат Telegram |
| 🔥 **Серия дней** | Сколько дней подряд готовишь по рулетке, плюс статистика и топы |
| 📦 **Обмен наборами** | Экспорт всех продуктов в код `FR1:…`, друг вставляет его у себя |
| 🌗 **Тема** | Тёмная / светлая / как в Telegram |

Данные (продукты, история, избранное) хранятся **на устройстве** в `localStorage` внутри Telegram.

## Структура

```
index.html        разметка экранов
css/style.css     стили (тёмная/светлая тема)
js/defaults.js    стартовые продукты, шутки, челленджи, палитра эмодзи
js/rules.js       что с чем не сочетается + формы слов для поиска рецептов
js/store.js       состояние, сохранение, экспорт/импорт
js/reel.js        бесконечный барабан (свайп, инерция, анимация)
js/fx.js          Telegram API, вибро, звук, конфетти, встряска, шаринг
js/app.js         экраны и логика
dev-server.js     локальный сервер для проверки
```

## Проверить локально

```bash
node dev-server.js
```

Откроется на http://localhost:5173. В обычном браузере всё работает, кроме фишек Telegram (вибро идёт через `navigator.vibrate`, если он есть).

## Запуск в Telegram

> 📘 Подробная пошаговая инструкция для новичков (GitHub через сайт или git, Pages, BotFather, обновления, частые проблемы) лежит в **[GITHUB.md](GITHUB.md)**. Ниже краткая версия.

### 1. Выложить файлы на HTTPS

Самый простой бесплатный вариант — **GitHub Pages**:

1. Создай репозиторий на GitHub (например, `food-roulette`) и загрузи туда все файлы из этой папки.
2. Открой **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)` → **Save**.
3. Через минуту приложение откроется по адресу `https://<твой-логин>.github.io/food-roulette/`.

Подойдут и другие хостинги: на **Netlify Drop** (app.netlify.com/drop) достаточно перетащить папку мышкой, есть ещё Vercel и Cloudflare Pages.

### 2. Создать бота и привязать приложение

В Telegram открой **@BotFather**:

1. `/newbot` → придумай имя и username (например, `my_food_roulette_bot`).
2. Кнопка в меню чата: `/mybots` → выбери бота → **Bot Settings → Menu Button → Configure menu button** → отправь ссылку из шага 1 → название кнопки, например `🎰 Крутить`.
3. *(по желанию)* Прямая ссылка на приложение: `/newapp` → выбери бота → название, описание, картинка 640×360 → ссылка из шага 1 → короткое имя (например, `app`). Получится ссылка `https://t.me/my_food_roulette_bot/app`, её можно кидать друзьям.

Теперь в чате с ботом слева от поля ввода появится кнопка, которая открывает рулетку.

### 3. Ссылка для «Поделиться» (по желанию)

В начале `js/app.js` укажи ссылку на приложение, чтобы она прикреплялась к сообщениям:

```js
window.APP_CONFIG = {
  botUrl: 'https://t.me/my_food_roulette_bot/app',
  ...
};
```

## Как поменять стартовые продукты

Отредактируй `js/defaults.js`: каждый продукт записан как `['Название', 'эмодзи']`. Стартовый набор используется при первом запуске и после «Сбросить всё».
